# MotionKey — Vision-Based Gesture Controller

MotionKey is a real-time computer-vision controller that converts body movements into keyboard commands for an Android endless runner running in BlueStacks.

## Features

- Lean left → Left Arrow
- Lean right → Right Arrow
- Jump → Up Arrow
- Crouch / squat → Down Arrow
- Live MediaPipe pose skeleton
- Calibration, smoothing, cooldowns, and neutral-reset logic
- Tested with Subway Surfers in BlueStacks

## Tech Stack

- Python
- OpenCV
- MediaPipe Pose
- PyAutoGUI
- BlueStacks
